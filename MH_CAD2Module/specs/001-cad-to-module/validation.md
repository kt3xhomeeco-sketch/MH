## Practical limits
This release recognises orthogonal cabinet panel assemblies with supporting section/plan geometry. Unsupported/ambiguous drawings stop with diagnostics and can enter explicit correction mode. Broad rule generalisation is not claimed; accepted examples replay only at matching geometry signature/version. Native template verification covered compatible static size; parametric templates use the installed MH Module Studio adapter with post-build dimension validation, but no universal template compatibility claim is made. Product boxes preserve construction offsets; this stage does not generate every panel, door or trim.
