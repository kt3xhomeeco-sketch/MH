# Data model
- Project: project UUID, source paths, library root (app-local by default, relocatable), converter/Python paths. Stored in model attributes and last-used preferences.
- BuildStages (0.4.0): project/preference booleans build_plan=true and build_elevation=false by default. Plan products carry build_stages, plan_only pipeline, height_source=provisional_default and default_height_mm=1600. Provisional corrections remain in history but are excluded from full-height learning.
- SourceRevision: SHA256, archived source, normalised DXF, units, dependencies. Original content immutable.
- Analysis: schema/version, revision hash, products, geometric signature, lines/rectangles, measurements, diagnostics.
- Product: code/name, source regions, bounds, modules, evidence. A module has local XYZ origin and W/D/H in mm, source handles and rule explanation.
- ProductInstance: analysis/job reference, code, local analysis bounds, label reference. Instance transformation anchors assembly to global X/Y/Z.
- CorrectionSession: UUID, baseline source/analysis/product snapshot. Lifecycle active -> saved/closed. Events carry before and after boxes plus immutable SKP component snapshots.
- Experience: exact geometry signature and original analysis version with corrected modules, provenance event ID. Reuse only explicit accepted corrections; undo/redo never promote examples.

## Similar-geometry experience (0.3.0)
- Active examples: latest valid accepted event per geometry signature/parser version; older accepted revisions remain immutable history. Independent examples that imply different layouts require review.
- DerivedRule: schema 3, content hash of the accepted event, checksum, construction-view incidence/profile graphs, physical plane sets and measured edge/centre bindings; stored under library/rules/v3/. A corrupt cache is rebuilt from the accepted event. No source/model dependency is read through its old path.
- LearningResult: mode exact|similar|review|unmatched, event/source product, agreeing examples, issues and partial-sample exclusions. Similar outputs carry six anchor_evidence faces with target handles/view coordinates and a target-front source_box for highlighting; source entity IDs and stale geometric proofs are removed.
- Similarity scope: same construction view/edge/profile incidence and unchanged measured stock. Different bay widths/heights/depths are permitted; arbitrary extra bays, profiles, nested panels and unbound planes are not inferred. Auxiliary parts retain roles/ownership. Partial samples do not authorize complete construction.

## Manual boxes (0.5.0)
- Manual correction session: original visibility, immutable original analysis/state, manual=true. As of 0.5.1, the live SketchUp selection is read and validated at acceptance; no pending source IDs or capture step are required.
- Accepted correction: input_axes_ignored=true, manual_source_ids, normalised_from and before/after/SKP; source IDs are provenance only, never required to replay. Product.manual_boxes=true; owned parts carry user-drawn-box-v1.
- Plan learning mode plan_exact: same geometry signature and parser version, accepted manual event, no vertical tiers; copied layout height becomes provisional 1600 mm. Target plan/source boxes are rebuilt at the current CAD envelope. These events remain excluded from full-height and topology-transfer examples.
- 0.5.4: CorrectionSession exposes original source_bounds/source_modules. Accepted events may carry plan_origin_offset_mm (bounded X/Y offsets from the CAD envelope) and relinked_from_event for audited binding repairs. Product placement/overlays include these offsets. experience_exclusions/<event-id>.json references a repaired wrong-source event and its replacement; original events/SKP remain immutable. Plan replay skips exclusions and diagnoses gross source-envelope mismatch. user_confirmed describes the current manually accepted layout; plan_exact describes a fresh scan that actually reused it.

## Circular plan profiles (0.6.0)
Optional `plan_profile: {schema:1, segments:[...]}` on module/trim parts. Coordinates are local XY millimetres relative to the part origin. A line has type/start/end; an arc additionally has center/radius/signed sweep in radians/segments integer. Boundary is one closed loop with no holes, extruded vertically by size[2]. The profile travels unchanged through accepted state and exact plan replay; native measurement recomputes it after editing. `source_plan_envelope` stores the complete measured CAD plan extent independently of accepted output or the previous rectangle-only envelope; source-binding validation uses it when present. No generalization/rescaling rule for curved profiles is claimed.

## Root Group assemblies (0.6.1)
Generated modules/auxiliaries are independent native Groups at model root. No product container or hidden controller geometry exists. Model dictionary `MH_CAD2Module_Assemblies` stores entries keyed by `assembly-<uuid>`, containing product attributes, source-frame matrix, name and explicit member persistent IDs. Each member carries `MH_CAD2Module/assembly_id`; inherited attributes on a copied Group alone do not enroll that copy. Deleted member IDs are ignored/pruned during subsequent membership updates. Legacy native product containers remain readable. `plan_origin_basis=source_plan_envelope` makes accepted/replayed normalized coordinates relative to full measured CAD. Legacy small offsets are translated into that frame without changing world placement; an incomplete last-bay envelope cannot offset a complete learned layout by thousands of mm.
