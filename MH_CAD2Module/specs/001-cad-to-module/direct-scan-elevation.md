# Combined direct scan — 0.17.0

When both Plan and Elevation settings are enabled, a single SketchUp scan collects coplanar CAD views plus native text, readable text-group metadata and section-symbol attributes. Keep plan-only capture/partition independent and preserve all existing source geometry, positions, labels and feedback. No AutoCAD launch, AI/OCR or C/Rust migration.

Project text anchors and symbol strokes using the same complete instance/edit transforms as source edges. Crop annotations to the scan window; partial symbols cannot authorize heights. Use measured cut direction and repeated endpoint IDs/paired symbol attributes; title "section2-2" alone never supplies orientation. Exclude recognized text/symbol graphics from construction geometry. Detect exploded cuts only with matching readable labels at both ends and one unambiguous line. Reuse existing view classification, stock-pair index and independent Z stage; missing/conflicting cuts retain provisional1600 mm boxes and explain the reason. Cache keys include annotation content; revalidate annotation identity/content/position before native build, including text-only changes while the worker runs.

Native output stays on each scanned plan's world position, never at the front/section drawing or label/inspection-row offset. No product code required. Preserve analytic/recovered arcs and all board standards. Measure capture/annotation, worker and native times separately. Test full/partial/missing/changed/rotated annotations, same-number different-direction cuts, shared source instances, multiple plans, plan-only isolation and source-bound native solids in aborted QA operations. Use the user's Untitled1 live plan read-only for regression; use isolated temporary QA geometry for full metadata cases, never replace user products.
