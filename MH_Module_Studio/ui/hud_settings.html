Cài đặt HUD

100% = vừa hình. Có thể tăng tới 300%; phần vượt vòng sẽ bị cắt. Viền và cỡ vòng giữ nguyên.

Theo chuột: mở tại con trỏ rồi giữ nguyên để chọn icon.

Kéo icon trên HUD để đổi chỗ. Hoặc mở Library, bật Edit HUD rồi kéo module vào một ô trên vòng.

Config HUD

Lưu vị trí icon, phím folder và cài đặt hiển thị để dùng lại.

Phím chọn folder

Gán một chữ A–Z. Các chữ còn lại dùng để tìm tên module; Backspace xoá tìm kiếm.

1–8 chọn · Tab đổi folder · ← → chuyển trang
Esc / Space thoát hoàn toàn HUD
