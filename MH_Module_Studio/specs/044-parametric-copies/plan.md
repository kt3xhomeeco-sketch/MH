# Plan

Use retained ATT to identify explicit leaf families by parent, expression set and
consecutive COPY index. Require one original and matching captured COPIES. Never
infer family identity from labels alone. Keep a stable template program; derive
extra part/node keys deterministically and preserve surviving keys/instances.

Upgrade existing exact ATT systems in memory, preserving symbols, custom
variables, current values, exposure flags and rule identity. Route topology
changes through DCCopies, with CopyRuntime owning native add/remove operations.
Keep the previous geometry/visibility/own-expression pipeline for unchanged
template topology. Guard unsupported subtree and rotation changes, including
rotations activated only on newly created COPY indices. Reconstruct after Scale
with the same portable family model and frozen inactive geometry.

Runtime, previews, sheet rows, native verification, file writes and Library
payloads must accept the evaluated part set rather than treating template part
count as the current count. Persist stable templates and per-instance values;
changing count back restores deterministic original keys.

Additional user request: expose original LIST controls. Decode actual installed
DC format (legacy %uXXXX/Latin-1 and percent UTF-8); LIST numeric lengths use
stored inch values, converted to own mm. Share decoded choice metadata in a
portable owner. Render numeric choice dropdowns in Parametric and Module Options,
preserve disabled diagnostics and never execute encoded expression/string values.
