# Custom ATT visibility and model sessions

Preserve custom ATT keys and report missing attributes on the drawer-front DC.
Do not confuse per-module variable symbols with shared cross-module bindings.
Fresh geometry fallback rows should retain the actual DC key instead of an
order-dependent att_1 name. Existing saved rows remain compatible.
Formula discovery must scan beyond the 120-row presentation inventory. Registered
functions still require complete nominal-reader verification; no imported code is
executed. The drawer root LenY remains a derived output of the custom panel
thickness, never an independent editable dimension.

Deleted-module links must disappear from the HUD/inspector and stop participating
in solving. Do not destroy persisted records during a read: Undo must restore a
deleted module and its original links. Locked modules and temporarily unavailable
panel references must not be mistaken for deleted modules.

After New/Open, discard stale native root handles, cancel old file-read callbacks,
rebind model observers and let Parametric/Module Options read the new model's own
saved rules. Switching sessions must not apply an old draft to a new PID. Do not
alter source SKPs or launch SketchUp. Verify custom/key isolation, deletion/Undo,
stale callbacks, native file import and a real New-model transition where safe.
