# Results and limits

The actual `1.CA Mat ngan keo.skp` contains 22 custom root attributes after
excluding standard DC/layout metadata. All are retained in the new parameter
inventory (T aliases can share one displayed variable). The previous inventory
contained 15 parameters. Supported geometry inputs remain editable; hidden
information and derived fields are readonly. Original formula evidence is shown
without submitting that text as a new own formula. Older payloads are supplemented
in memory and existing symbols are preserved; original keys replace att_1-style
generated names only on new fallback reads. An old geometry-only payload without
its original ATT program cannot reconstruct data that was never saved; reread
the original DC in that case.

Same symbols across modules remain scoped by each rule and instance/member PID.
Only explicit common T1/T2 grouping couples module inputs. Tests cover two
independent att_1 variables with different values.

`outputs/session-068/native-check.json` records actual SketchUp execution through
VBO PID17900/port7891. File New was performed only from the user's clean empty
Untitled model. It reproduced reuse of the same Ruby Model object. Old busy/PID
state cleared; a preview cached before New imported afterward; Parametric and
Module Options read that new instance's own rules. A private drawer DC copy
retained all 22 custom attributes and changed T to 20 mm and back with native
geometry verification. Real deletion hid a link, Undo restored it and Undo of
fixture creation removed all test geometry. Final model entity count was zero.
The successful report's retained checks were restored after a later guarded
attempt reused the old report object. That later attempt stopped before New
because the user had added geometry; the helper now clears the old report before
its guard. Later-added thumbnail/session-token native assertions were not rerun
against the user's nonempty model; input-session isolation passed in Chromium.

The user then selected native PID453467, Door, from `1.CA Mat ngan keo.skp`.

display formulas. The functions already existed but some references appeared
later; discovery now scans the complete inventory while preserving bytecode

`outputs/session-068/selected-check.json` records the actual selected DC's 22
custom attributes with no omissions and a translated formula engine. An aborted

Portable checks cover original-key collisions, cached formula units, actual
drawer attributes, omitted-Access output versus TEXTBOX, serialization, old rule
upgrade, stale async callbacks and invalid Model observer cleanup. Chromium
checks cover original readonly formula display, checkbox save payloads, a cleared

new model reuses the selected PID.
Final gate: 191 Ruby files clean, 353 tests / 4206 assertions, zero failures,
errors or skips. Both relevant Chromium checks passed. The explicit runtime
package was built and checked; the runtime was reloaded in the existing SketchUp.

This work does not resolve the separate hidden-alternative envelope conflict of
the 2.CA drawer variant or the 1.CA drawer's uniform XYZ Scale verification. An
attempted private conversion correctly rejected those Scale conditions. No
unsupported conversion was published and source SKPs were not rewritten.
