# Linking display lifetime and door Replace thickness

Saved contact dimensions, prisms and draft highlights appear only while the
module-linking Tool is active. Switching to Select/Move/Scale or closing the
linking HUD hides them immediately; inactive overlay extents must also be empty.
Keep saved relationships and the session data available when returning to linking.
Library import host highlights remain governed by the separate placement Tool.

Library Replace using a door sample preserves its actual source thickness, and
fits the other two dimensions to the real target block. Keep the target's front
datum (opposite the sample's mounting side), orientation and position. Apply to
preview, repeated click Replace and preselected batches, including scaled/mirrored
frames. Door role comes from saved metadata, even if import linking is disabled;
ordinary samples keep their existing strict envelope policy. Preserve source T,
ATT rules, independent identities, existing contacts and atomic error rollback.

Verify portable thickness-plane calculations, linking lifecycle and native actual
replacement bounds/T/independence. Run scoped gate and verify runtime packaging;
use existing SketchUp sessions only and leave user models/preferences unchanged.
