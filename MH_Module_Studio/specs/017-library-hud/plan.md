# Implementation

Portable catalog handles canonical folder boundaries, validated settings, file
fingerprints, versioned embedded payloads and HUD geometry/search. Native adapter
extracts SKP thumbnails without opening models, exports a private temporary copy
then aborts its transaction, and stamps independently imported instances. Native
Tool draws textures/circles in logical pixels and owns browsing and placement.
The main HtmlDialog receives Library state on a separate callback so ordinary
Studio publications never resend the thumbnail catalog or lose form drafts.

Checks: scoped RuboCop plus Ruby regressions, real Chromium UI smoke, VBO native
round trip, identity, geometry/Undo, drawing and keyboard. Package explicit runtime
manifest. Do not claim unexecuted native key tests or modify user shortcuts.
