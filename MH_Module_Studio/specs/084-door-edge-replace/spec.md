# Door edge targeting and repeated Replace performance

When importing a door from Library in Auto mode, front rim faces of a cabinet
must be easy to acquire, including narrow 18 mm edges. Accept a 12 logical-pixel
band around real mounting-face triangles; prefer that front mount over an inset
seed only within the band. Keep the middle of the cavity available for inset.
Only the host's real matching faces highlight. Explicit Inside remains Inside;
wrong-side/rear or hidden faces must not trigger a front mount. Empty space near
the front rim may resolve the nearest eligible visible cabinet without inventing
surfaces or modifying geometry. Pointer preview and placement click share detection.

Profile single-click repeated Library Replace using private temporary targets.
Optimize demonstrated repeated work while retaining real target dimensions,
physical T/ATT validation, independent identities, rollback and existing contacts.
No global loosening of geometry checks and no reuse of mutable native instances.

Verify portable hit distances, native exact/narrow-edge/near-edge/inset cases,
scaled/rotated hosts, repeated Replace geometry and measured before/after timing;
run the scoped gate and build/verify the runtime package. Preserve user models,
preferences and concurrent plugin changes.
