# Create model from the main window

Add Tạo model immediately beside the existing Lưu quy tắc button in the main
Studio window. Generate real native groups from the read snapshot and saved
formula/variable values, including own part-cell formulas. A selected source is
not required. Retain source/model template data; select the created root.

Generate verified rectangular panels only, using the planned bounds in mm.
All saved geometric inputs take part in creation, regardless of tick choice;
calculate on a temporary rule copy and retain the original checkbox metadata.
Keep stable part keys/names/visibility and own rule/parameter metadata. Reject
unsupported geometry, stale identities and unsafe calculations before creating
entities. One native operation, rollback on failure, independent definitions.
Create at module coordinates in the active model, without importing through DC
or MH_superimp. Existing update/capture must recognize the generated own module.

This request implements the main button/generator. The compact live parameter
window and visibility-only checkbox behavior remain a separate feature.
