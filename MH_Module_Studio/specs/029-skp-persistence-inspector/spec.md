# 029 — Direct SKP persistence and usable assembly inspector

Persist Parametric edits (including symbol renames and dependent formulas) directly
in the originating module SKP, with explicit Save SKP, optimistic file signatures,
backup and verification. Restore own payload on reopen. Add Read SketchUp to the
Parametric window. Keep model geometry selection and gizmos native, but replace
the crowded draw2d controls with a compact utility HtmlDialog matching the approved
light CAD inspector. Selecting an opposing boundary enters Fit and resizes B when
complete; a checkbox switches Fit/Center without losing anchors. Do not overwrite
the open whole-model SKP with a component export. Verify source hashes and native
model preservation; run the existing gate and package the new assets.
