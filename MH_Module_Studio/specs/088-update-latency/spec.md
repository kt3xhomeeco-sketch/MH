# 088 — Reduce blocking after module size changes

Size edits must retain exact ATT/T, the requested construction envelope and one
atomic redraw/contact transaction. Reduce time spent on duplicate calculation;
do not relax final native geometry verification or split dependent work into
visible intermediate geometry.

- Profile actual MH_stretch and module parameter paths using private fixtures.
- Reuse portable Scale plans only within one repair, keyed by complete rule,
  current measured geometry and values. Capture fresh native bindings on apply.
- Reuse one custom-attribute evaluator per variable evaluation, resetting values
  for each custom field. Do not retain mutable evaluator state between modules.
- Avoid variable evaluation when a module has no own part-cell formulas.
- Validate the rule once at the entry point, pass that in-memory proof through
  the nested scale/rule/engine calculation, and keep ordinary public entry
  points validating by default. A saved JSON flag must not bypass validation.
- Preserve source model/selection/preferences. Measure work independently from
  debounce/test polling latency; report the scope and actual timing limits.
